# Калькулятор полиграфических операций

Статическое веб-приложение для расчёта шести операций УФ-лакирования и
фольгирования. Позволяет добавлять операции, получать итоговые суммы и
экспортировать рапортичку в PDF или TXT.

## Ссылки

- Публичная страница: `https://sunpole.github.io/001-print-operations-calculator/`
- Исходный код: `https://github.com/sunpole/001-print-operations-calculator`
- Карточка в SUNPOLE HUB: будет ссылаться на этот репозиторий после отдельного PR.

## Запуск

Откройте `index.html` в современном браузере. Приложение статическое и не
требует установки зависимостей.
